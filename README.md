# 🖥️ অণুরণ ওএস টার্মিনাল (Onuron OS Terminal App in Nilang)

অণুরণ ওএস (Onuron OS)-এর জন্য সম্পূর্ণ **নীলাং (Nilang)** ভাষায় লিখিত প্রিমিয়াম, ফিচারে ভরপুর ও দৃষ্টিনন্দন ইন্টারঅ্যাক্টিভ টার্মিনাল অ্যাপ।

---

## ✨ বৈশিষ্ট্যসমূহ (Features)

- 🎨 **কাস্টম থিম সাপোর্ট**:
  - 💚 **Cyberpunk / Matrix Green** (`#00E5FF` / `#00FF66`)
  - 💜 **Dracula Purple** (`#BD93F9` / `#FF79C6`)
  - 💙 **Nordic Freeze** (`#88C0D0` / `#E5E9F0`)
  - 🧡 **Solarized Flame** (`#CB4B16` / `#B58900`)

- 📑 **মাল্টি-সেশন ও ট্যাব সাপোর্ট (Multi-Session Tabs)**:
  - একসাথে একাধিক টার্মিনাল সেশন (Tab 1, Tab 2, Tab 3) খোলা এবং সুইচ করার সুবিধা।

- ⚡ **বিল্ট-ইন অণুরণ কমান্ড সিস্টেম (Built-in Commands)**:
  - `help` / `কমান্ড`: উপলব্ধ সমস্ত কমান্ড ও ব্যবহারের গাইড।
  - `sysinfo` / `সিস্টেম`: CPU, RAM, OS ভার্সন ও আর্কিটেকচার ইনফরমেশন।
  - `ls` / `cd` / `pwd` / `cat`: ফাইল সিস্টেম ট্রাভার্সাল ও ফাইল রিডার।
  - `nilpkg`: অনুরণ প্যাকেজ ম্যানেজার ইন্টারফেস।
  - `softbus`: সফটবাস IPC স্ট্যাটাস ও কানেক্টেড ডিভাইসের তালিকা।
  - `top` / `ps`: রিয়েল-টাইম প্রসেস মনিটর।
  - `theme`: রিয়েল-টাইমে থিম পরিবর্তন।
  - `clear`: টার্মিনাল স্ক্রিন ক্লিন করা।

- 💡 **অটো-কমপ্লিট ও ইতিহাস (Autocomplete & History)**:
  - পূর্ববর্তী কমান্ড হিস্ট্রি (Up/Down) এবং দ্রুত কমান্ড সিলেক্টর।

- 📱 **অ্যান্ড্রয়েড নেটিভ APK সাপোর্ট (.apk)**:
  - রিপোজিটরির রুটে সরাসরি বিল্ড করা `onuron-terminal.apk` ফাইল রয়েছে, যা যেকোনো অ্যান্ড্রয়েড ডিভাইসে ইন্সটল করা যাবে।

## 🚀 রান ও বিল্ড নির্দেশিকা (How to Run & Build)

### ১. নীলাং কম্পাইলার দিয়ে স্থানীয়ভাবে রান করুন:
```bash
nil run src/main.nil
```

### ২. UI রেন্ডার প্রিভিউ দেখুন:
```bash
nil render src/main.nil
```

### ৩. `.nilax` বান্ডিল তৈরি করুন:
```bash
nil build
```
