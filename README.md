# Onuron OS Terminal (অণুরণ ওএস টার্মিনাল) 🖥️📱

**Onuron OS Terminal** হলো **নীলাং (Nilang)** ভাষায় লিখিত একটি আধুনিক, দ্রুত এবং সুন্দর মোবাইল ও ডেক্সটপ টার্মিনাল অ্যাপ্লিকেশন। এতে অ্যান্ড্রয়েড ফাইল সিস্টেম নেটিভ অ্যাক্সেস এবং বিল্ট-ইন পাইথন ইঞ্জিনের সুবিধা যুক্ত করা হয়েছে।

## ✨ ফিচারসমূহ (Features)

1. **নীলাং ভাষায় রচিত (Nilang Native App)**
   - সম্পূর্ণ কোর অ্যাপলিকেশন লজিক এবং স্টেট নীলাং ভাষায় তৈরি।
2. **অ্যান্ড্রয়েড ফাইল সিস্টেম ইন্টারঅ্যাকশন (Native Android FS)**
   - সরাসরি অ্যান্ড্রয়েড ডিভাইস ফাইল সিস্টেমে ডিরেক্টরি ব্রাউজ, তৈরি এবং ফাইল এডিটিং করার ক্ষমতা।
   - সাপোর্টেড ফাইল কমান্ড: `ls`, `pwd`, `cd`, `mkdir`, `touch`, `cat`, `echo`, `rm`
3. **পাইথন ইন্টারপ্রিটার এবং আরইপিএল (Python Engine & REPL)**
   - টার্মিনাল থেকেই পাইথন স্ক্রিপ্ট চালানো (`python hello.py`), সরাসরি পাইথন কোড রান করা (`python -c "..."`) এবং ইন্টারেক্টিভ পাইথন কনসোল (`python` REPL mode `>>>`) চালনা করা।
4. **কেস-ইনসেনসিটিভ কমান্ড প্রসেসিং**
   - ছোট হাত বা বড় হাতের অক্ষর যেভাবেই লিখুন না কেন (`ls`/`Ls`, `pwd`/`Pwd`), সমস্ত কমান্ড সঠিকভাবে কাজ করে।
5. **সাইবারপাঙ্ক ও ম্যাট্রিক্স থিম ডিজাইন (Modern Visual UI)**
   - রেসপন্সিভ সাইবারপাঙ্ক হেডার, কুইক-অ্যাকশন টুলবার চিপস এবং রিয়েল-টাইম টার্মিনাল ফিডব্যাক কনসোল।

## 🚀 কমান্ড নির্দেশিকা (Command Usage)

| কমান্ড | বিবরণ |
|---|---|
| `ls` / `ls -la` | ফাইল এবং ডিরেক্টরির তালিকা প্রদর্শন |
| `pwd` | বর্তমান ডিরেক্টরি পাথ প্রদর্শন |
| `cd <folder>` | নির্দিষ্ট ডিরেক্টরিতে গমন |
| `mkdir <folder>` | নতুন ডিরেক্টরি তৈরি |
| `touch <file>` | নতুন খালি ফাইল তৈরি |
| `cat <file>` | ফাইলের কনটেন্ট পড়া |
| `echo "hello" > file.txt` | ফাইলে টেক্সট লেখা / যুক্ত করা |
| `rm <file>` | ফাইল বা ডিরেক্টরি মুছে ফেলা |
| `python <script.py>` | পাইথন স্ক্রিপ্ট এক্সিকিউট করা |
| `python` | পাইথন REPL ইন্টারেক্টিভ মোডে প্রবেশ (প্রস্থান করতে `exit()` লিখুন) |
| `sysinfo` | অনুরণ ওএস সিস্টেম আর্কিটেকচার ও মেমোরি ইনফো |
| `services` | রানিং সিস্টেমে অনুরণ সিস্টেম ডেমনের তালিকা |
| `clear` | টার্মিনাল স্ক্রিন পরিষ্কার করা |

## 📦 অ্যাপ বিল্ড এবং ইনস্টলেশন (Building APK)

প্রজেক্টের রুট ডিরেক্টরিতে `.apk` তৈরি করতে নিচের কমান্ডটি রান করুন:

```bash
go run /tmp/nil_android_builder_v2.go src/main.nil onuron-terminal.apk
```

তৈরি হওয়া `/app/onuron-terminal.apk` ফাইলটিযেকোনো অ্যান্ড্রয়েড ডিভাইসে সরাসরি ইনস্টল করা যাবে।
